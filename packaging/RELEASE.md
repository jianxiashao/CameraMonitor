这一版把界面重新排了一遍，并加上现场最常用的巡检、自检与运维工具。

## 0.10.0 新增

- 界面重排：顶部品牌栏、侧栏卡片、工具栏浮动卡片、深色圆角监控墙、卡片式设备行；浅色/深色统一圆角、悬停和选中态。
- 新增「关于 Camera Monitor」：版本、运行环境、数据目录、项目链接和复制版本信息；托盘菜单也能打开。
- 海康 SADP 自动发现（型号、序列号、ONVIF 地址），与 ONVIF / 大华发现结果按 IP 合并。
- 手动 RTSP 添加：萤石等只开 RTSP 的摄像头、海康 NVR 通道可直接填地址添加，账号密码自动存入系统安全存储。
- ONVIF 云台方向控制、缩放和预置位；一键校准相机时间。
- 告警记录（SQLite + CSV）、系统通知、Webhook；巡检截图叠加名称/IP/时间并生成 HTML 报告。
- 回看默认最新一段，支持从头播放和 1x–8x 倍速。
- 布局方案、每路画面比例、设备列表右键菜单、窗口大小记忆、检查更新、云端服务器地址。
- 崩溃后自动重启（守护模式）；傻瓜模式默认开启。
- 25 路场景大幅降负载：背景格 10fps、解码宽度随格子、缩略图 640、录像只查一次磁盘。

## 界面

- **顶部品牌栏**：程序图标、标题、副标题和 ONVIF / 大华 DHIP / 海康 SADP 徽标；全屏时自动隐藏。
- **两张工具栏卡片**：上面是标题、横向铺满和右侧操作组（一键重连 → 一键断开 → 巡检功能 →
  云端同步 → 连接设置 → 设置 → 全屏），下面是分屏布局。常用的都靠右。
- **侧栏卡片**：搜索、手动 RTSP、按 IP 添加、设备数量徽标和卡片式设备行；选中行有蓝色强调边。
- **「设置」菜单**收口所有配置：机构名称、大屏密码、启动选项（开机自启 / 启动全屏 / 守护模式）、
  布局方案、批量账号密码、导出诊断包、巡检截图保存位置、配置导入 / 导出、深色 / 浅色主题、
  每天自动重启、告警记录、告警 Webhook、云端服务器地址、检查更新、关于。
- **右侧「连接设置」**是 344px 宽的浮层，关闭时完全不占画面宽度。
- **监控墙**：深色圆角画布、格子间 4px 间距、虚线空位；全屏时自动去掉圆角和工具栏。

## 巡检功能

工具栏「巡检功能」菜单里两项：

- **一键检测**：逐路重新取一次画面，汇总正常 / 异常 / 未播放各多少路，明细列出具体 IP
  与延迟。结果同时写进左侧状态栏并弹出明细框；大屏或傻瓜模式下只写状态栏与日志，不挡画面。
- **巡检截图**：把每路当前画面存成 JPG，统一放进保存根目录的**当天日期文件夹**。
  文件名用摄像头名称 + 截图时刻（`大门口_203445.jpg`），没名称用 IP（`10_0_0_5_203445.jpg`），
  同一秒重名自动加 `-2`、`-3` 不覆盖。截图会叠加名称、IP 和时间，并生成 `巡检报告.html`。
  保存位置在「设置 → 巡检截图保存位置…」里选一次即可，第一次点按钮会先提示设置。

## 画面自检与回看

- 每格画面右上角**延迟指示灯**：绿=实时、黄=略滞后、红=正在追帧。
- **黑屏告警**：连上了却一直是黑画面时，画面上出现红条提示，恢复后自动消失；判定只抽样 64 个点。
- **环形回看**：每路按 1 帧/秒、宽 480 存最近 10 分钟（系统临时目录，1 分钟一段滚动删除）；
  默认从最新一段开始，可切换从头播放和 1x–8x 倍速，回答"刚才那几分钟发生了什么"。

## 无人值守与运维

- **导出诊断包**：运行日志、脱敏设置、各路连接诊断打成一个 zip，不含摄像头密码与云端令牌。
- **配置导入 / 导出**：相机清单、名称、标注、排列顺序与传输方式导出成 json，方便批量部署。
- **每天自动重启**：可选固定时间重启一次，兜底内存 / 句柄缓慢增长；重启后自动回到大屏。
- 崩溃日志（`crash.log`）、单实例锁、看门狗自动拉起。
- 云端可观测性：现场健康状态（每路是否在播、延迟、告警、重连次数、CPU / 内存）上报到后台。

## 安装

Windows 11 x64：下载 `CameraMonitor-Windows11-x64.zip`，解压后运行 `CameraMonitor.exe`，
不需要安装 Python。

macOS 14+ Apple M 系列：解压后把 `Camera Monitor.app` 拖进「应用程序」。
