这一版把界面重新排了一遍，并加上现场最常用的巡检、自检与运维工具。

## 界面

- **顶部工具栏右侧统一右对齐排成一行**：一键重连 → 一键断开 → 巡检功能 → 云端同步 →
  连接设置 → 设置 → 全屏。左边是标题与「横向铺满」，中间留白，常用的都靠右。
- **「设置」菜单**收下了所有配置入口：机构名称、大屏密码、开机自动启动、启动后自动全屏、
  批量账号密码、导出诊断包、巡检截图保存位置、配置导入 / 导出、深色 / 浅色主题、每天自动重启。
  原来散在侧边栏的「更多操作」已经去掉。
- **右侧「连接设置」不再挤占画面**：去掉了常驻的竖排标签和它预留的 42px 右边距，
  监控墙铺满整个工作区；面板改成 336px 宽的浮层，关闭时完全不占位。
- 新增**深色主题**，夜间值守可一键切换，选择会记住。

## 巡检功能

工具栏「巡检功能」菜单里两项：

- **一键检测**：逐路重新取一次画面，汇总正常 / 异常 / 未播放各多少路，明细列出具体 IP
  与延迟。结果同时写进左侧状态栏并弹出明细框；大屏或傻瓜模式下只写状态栏与日志，不挡画面。
- **巡检截图**：把每路当前画面存成 JPG，统一放进保存根目录的**当天日期文件夹**。
  文件名用摄像头名称 + 截图时刻（`大门口_203445.jpg`），没名称用 IP（`10_0_0_5_203445.jpg`），
  同一秒重名自动加 `-2`、`-3` 不覆盖。保存位置在「设置 → 巡检截图保存位置…」里选一次即可，
  第一次点按钮会先提示设置。

## 画面自检与回看

- 每格画面右上角**延迟指示灯**：绿=实时、黄=略滞后、红=正在追帧。
- **黑屏告警**：连上了却一直是黑画面时，画面上出现红条提示，恢复后自动消失；判定只抽样 64 个点。
- **环形回看**：每路按 1 帧/秒、宽 480 存最近 10 分钟（系统临时目录，1 分钟一段滚动删除），
  回答"刚才那几分钟发生了什么"。

## 无人值守与运维

- **导出诊断包**：运行日志、脱敏设置、各路连接诊断打成一个 zip，不含摄像头密码与云端令牌。
- **配置导入 / 导出**：相机清单、名称、标注、排列顺序与传输方式导出成 json，方便批量部署。
- **每天自动重启**：可选固定时间重启一次，兜底内存 / 句柄缓慢增长；重启后自动回到大屏。
- 崩溃日志（`crash.log`）、单实例锁、看门狗自动拉起。
- 云端可观测性：现场健康状态（每路是否在播、延迟、告警、重连次数、CPU / 内存）上报到后台。

## 安装

Windows 11 x64：下载 `CameraMonitor-Windows11-x64.zip`，解压后运行 `CameraMonitor.exe`，
不需要安装 Python。

macOS 14+ Apple M 系列：解压后把 `Camera Monitor.app` 拖进「应用程序」。

## 验证

620+ 项自动化测试通过（Windows 与 macOS 打包机上各跑一遍），产物经真实启动验证：
