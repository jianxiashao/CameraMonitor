# Camera Monitor · Windows 11 64 位

## 使用成品

将打包生成的 CameraMonitor.exe 复制到目标电脑，双击启动，无需安装 Python。
首次启动会解压内置组件，可能稍慢。请等待主窗口出现。

- 电脑与摄像头连接到同一局域网，点击“搜索设备”。
- 若 Windows 防火墙询问网络权限，允许此程序访问你信任的专用网络；不需要关闭防火墙。
- 已知 IP 但自动搜索不到时，点击左侧“按 IP 添加”，输入摄像头 IPv4 地址，识别后填写连接账号密码。
- 双击设备直接尝试连接；需要认证时，在连接设置中输入账号密码。
- 记住密码使用当前 Windows 用户的凭据管理器；不会随 exe 带入其他电脑。
- 视频中断后，每次等待 3 秒重试；停止按钮可取消。

本版目标为 Windows 11 x64（Intel / AMD）。已由使用者在 Windows 实机运行，并确认 UDP 模式播放稳定。
未配置 Windows 代码签名，可能显示未知发布者提示。遵循所在电脑的安全策略。

## 监控操作

- 顶部直接选择 4 / 9 / 12 / 16 / 20 / 25 格，或从下拉菜单选择 6 / 10 / 15 格一大多小。
- 摄像头不足时保留占位；可以将画面拖到另一个画面或空位，并记住位置。
- 左侧紧凑列表显示预览缩略图，点击看最近抓取的大图；暂无凭据时先连接设备。
- 单击监控画面放大，再次单击还原。
- F11 进入全屏；退出需要输入大屏密码，初始为 `000000`。恢复初始密码也需要当前密码。
- 全屏仍可放大、还原和拖拽。应用内密码锁不能阻止系统强制结束进程。

### 顶部工具栏

第一行右侧是一整组操作，从右到左依次是：

| 按钮 | 作用 |
| --- | --- |
| 全屏 | 等同 F11 |
| 设置 | 机构名称、大屏密码、开机自动启动 / 启动后自动全屏、批量账号密码、导出诊断包、巡检截图保存位置、配置导入导出、深色 / 浅色主题、每天自动重启 |
| 连接设置 | 先在左侧选中设备，再从右侧浮出它的连接参数面板；关掉不占画面 |
| 云端同步 | 输入授权码后与云端同步；未登录时显示授权码输入框 |
| 巡检功能 | 一键检测 + 巡检截图（见下） |
| 一键断开 / 一键重连 | 停掉全部画面 / 停掉后重新连接（换过密码、摄像头断网后用） |

### 巡检功能

- **一键检测**：逐路重新取一次画面，结果会写进左侧状态栏，并弹出明细框，
  列出正常 / 异常 / 未播放各多少路以及具体 IP 与延迟。
- **巡检截图**：把每路当前画面存成 JPG，统一放进保存根目录的**当天日期文件夹**，
  例如 `D:\巡检截图\2026-10-22\大门口_203445.jpg`。
  - 文件名用摄像头名称；没起名字的设备用 IP（点换成下划线，`10_0_0_5_203445.jpg`）。
  - 同一秒重名自动加 `-2`、`-3`，不会覆盖已有文件。
  - 保存位置在「设置 → 巡检截图保存位置…」里选一次即可；第一次点「巡检截图」会先提示设置。
  - 没在播放的摄像头会退回用列表里最近一次的缩略图；两者都没有的会在结果里列出来。

### 画面自检

- 每格右上角的**延迟指示灯**：绿=实时、黄=略滞后、红=正在追帧。
- 画面持续全黑时会出现红色告警条，画面恢复后自动消失。
- 每路按 1 帧/秒存最近 10 分钟的缩时画面，用画面上的「回看」查看刚才发生了什么
  （存在系统临时目录，重启后清空）。

## 在 Windows 生成 exe

编译电脑需先安装 Python 3.12 64 位（x64）及 Python Launcher，并能联网下载依赖。
将本项目源代码复制到 Windows，双击根目录 build-windows.bat。
脚本会安装依赖、运行测试、打包并检查 exe 的 x64 格式。
成功后成品位于 dist-win/CameraMonitor.exe，仅需把这个 exe 发给使用者。

发布前请在 Windows 11 实测：搜索摄像头、双击连接、多个画面播放、
记住密码后重新打开软件、断流后重连、停止和关闭窗口。
格式检查与自动测试不能代替这些实机验收。

## GitHub 云端编译

仓库已包含 `.github/workflows/windows-exe.yml`。它**只在手动运行时构建**，
改代码 push 到 main 不会自动触发：在仓库 Actions → Build Windows x64 EXE → Run workflow 启动。
流程使用 Windows 云端环境和 Python 3.12 x64，自动运行 Lint、全量测试、打包、
检查 exe 架构，并真启动一次主窗口，确认视频解码、云端 wss（TLS）和系统密码存储组件能加载。

成功后，脚本会把 `CameraMonitor-Windows11-x64.zip` 上传到 `v{版本号}` 的 Release
（版本号取自 `camera_monitor/__init__.py`，已存在就覆盖同名资产），可以长期下载。
同一次运行页面的 Artifacts 里也有同样的文件，保留 14 天。
云端无法访问你的内网摄像头，真实搜索、播放和密码保存仍需在目标电脑验收。
